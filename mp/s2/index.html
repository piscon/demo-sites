小程序模拟样板
MP-S2 目录型 × 机械包

微信小程序业务线第二个骨架样板：产品目录即核心，面向产品线较多的企业选型场景。与 MP-S1 展示型共用同一份内容包数据，界面层独立实现。

样板构成

  • 骨架：MP-S2 目录型 · 精简 3 栏（用户定版 tab 架构标准：适合产品线单一或重展示的工厂 / B2B 企业）
  • 栏位：首页（品牌形象 / 核心亮点 / 企业简介融入本页 / 末尾以主推产品与分类深链分发）· 产品中心（目录主场：左侧分类导航 + 规格速览密集列表 + 常驻搜索）· 联系我们（资质荣誉 / 工厂地址与导航 / 询盘联系方式 / 在线留资表单）
  • 与 MP-S1 的分工：S1 是展示型（经典 4 栏，重品牌展示与动态背书）；S2 是目录型（精简 3 栏，重目录浏览与选型效率），本骨架不设动态栏
  • 转化设计：产品详情页固定悬浮一键拨号 + 在线客服（动作不印号码）；联系方式全文只在联系我们栏出现一处；企业简介全文只在首页一处
  • 内容包：机械设备 · 恒力重工（与官网演示站同一份数据）
  • 主题色：内容包品牌 accent 安全黄 #E4AF00
  • 可点动线：栏位切换、轮播、分类导航、搜索筛选、详情进出、悬浮拨号 / 客服、复制 / 导航、留资表单提交（均为模拟反馈）

能力边界（诚实口径）

本样板为网页模拟效果，用于选型演示；微信登录、支付、分享等原生能力以原生交付为准。签约后按本样板 1:1 翻译为原生小程序（TDesign 组件同源）。

操作提示：直接点手机里的底部 tabBar、左侧分类轨与产品卡片体验目录动线；所有「拨打 / 复制 / 询价」动作都会给出模拟反馈 toast，不会真的外呼或提交。
