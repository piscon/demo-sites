小程序模拟样板
MP-S3 服务型 × 机械包

微信小程序业务线第三个骨架样板：面向带业务交互的企业，签名能力是「询价单」任务流——从产品详情把产品攒进询价单、一次提交留资，企业在「我的」里留痕可查。与 MP-S1 / MP-S2 共用同一份内容包数据，界面层独立实现。

样板构成

  • 骨架：MP-S3 服务型 · 扩展 5 栏 · 交易/留资型（用户定版 tab 架构标准：适合中大型企业或带业务交互的官网）
  • 栏位：首页（app 式连续流：Banner + 主张一行 / 分类大图卡 / 亮点·简介·资质·统计流内单点 / Pickup 策展收尾）· 产品中心（常驻搜索 + 目录浏览 + 快速加入询价单）· 案例动态（信任背书，动态全文单点；案例待真实数据接入后合并）· 询价单（攒单 → 改量备注 → 留资提交 → 生成本地记录）· 我的（询价记录 / 收藏 / 最近浏览 / 企业联系卡）
  • 设计参照：泉株式会社 izumi.inc（用户钦定品质标杆）——克制与留白、小标签 + 大图卡、Pickup 式策展；取其语言不搬其网站版式
  • 与 MP-S1 / S2 的分工：S1 展示型（经典 4 栏，重品牌展示）；S2 目录型（精简 3 栏，重目录选型）；S3 服务型（扩展 5 栏，重询价与客户自助交互）
  • 状态口径：询价单、收藏、询价记录、最近浏览均存浏览器本地（localStorage，按内容包隔离），刷新不丢；原生交付时对应微信端本地缓存与账号体系
  • 转化设计：详情页核心动作 = 加入询价单 / 立即询价，固定悬浮一键拨号 + 在线客服（动作不印号码）；联系方式全文只在「我的」企业联系卡出现一处
  • 内容包：机械设备 · 恒力重工（与官网演示站同一份数据）
  • 主题色：内容包品牌 accent 安全黄 #E4AF00
  • 可点动线：栏位切换、轮播、分类筛选、目录搜索、详情进出、收藏、加入询价单、询价单增删改量与备注、留资提交、记录查看（均为模拟反馈，状态本地保存）

能力边界（诚实口径）

本样板为网页模拟效果，用于选型演示；询价提交为模拟动作、不会真实发送，提交记录仅保存在本机浏览器。微信登录、支付、分享等原生能力以原生交付为准。签约后按本样板 1:1 翻译为原生小程序（TDesign 组件同源）。

操作提示：在产品详情点「加入询价单」攒单，去「询价单」栏改数量、填备注并提交，再到「我的」查看询价记录；所有提交均为模拟反馈，不会真的发送。
