小程序模拟样板
MP-S1 展示型 × 机械包

微信小程序业务线第一个可点击样板：手机壳内页面按 TDesign 组件外观与《微信小程序设计指南》渲染，内容全部由官网内容包驱动。

样板构成

  • 骨架：MP-S1 展示型 · 企业官网经典 4 栏（用户定版 tab 架构标准：微信规范 2–5 栏、落地主流 3–4 栏）
  • 栏位：首页（app 信息流：瘦身 Banner → 主张提炼行 → 金刚区（只放产品分类：上产品图 + 下分类名，单行横滑——产品分类 4–8 个全量入格、超过 8 个按产品数取前 8、不足 4 个整区不渲染，点击预筛产品中心，数据驱动、与展示预设无关）→ 主推产品流（Pickup 精选 + 产品卡，主推封顶 6 件；分类大图卡已于第九轮取消）→ 企业实力聚合区（按展示配置动态渲染楼层：有啥展示啥、无数据不留空板块，楼层均为预览入口 + 锚点深链）→ 底部转化区）· 产品中心（搜索 / 分类 / 规格参数 / 询价，核心转化区）· 动态（信任背书：案例与企业动态，全文单点落此栏）· 关于我们（简介全文 / 工厂实景与资质荣誉 / 地址导航 / 联系方式 / 在线留资表单）
  • 转化设计：产品详情页与关于我们页固定悬浮一键拨号 + 在线客服（动作不印号码）；联系方式全文只在关于我们出现一处
  • 内容包：机械设备 · 恒力重工（与官网演示站同一份数据）
  • 主题色：内容包品牌 accent 安全黄 #E4AF00
  • 展示预设：—（内容决定首页形态：组件开关 / 排序 / 推首页由预设生成，配置见 packs-display/）
  • 可点动线：栏位切换、轮播、分类筛选、搜索、详情进出、悬浮拨号 / 客服、复制 / 导航、留资表单提交（均为模拟反馈）

能力边界（诚实口径）

本样板为网页模拟效果，用于选型演示；微信登录、支付、分享等原生能力以原生交付为准。签约后按本样板 1:1 翻译为原生小程序（TDesign 组件同源）。

操作提示：直接点手机里的底部 tabBar、产品卡片与按钮体验动线；所有「拨打 / 复制 / 询价」动作都会给出模拟反馈 toast，不会真的外呼或提交。
