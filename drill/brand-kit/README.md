给「恒晟减速机（HENGSHENG GEARBOX）」演示站配套的品牌素材包：标志全套、站点图标、社交分享图、页面装饰、
导航图标、代码片段与页面状态图，一共九个部分。**先打开同目录的 `index.html`**，
全部素材的实际样子、深浅底效果与可复制代码都在那一页里；本文件只讲规则。

## 先看这三件事

1. **页头用哪一版**：桌面页头用「01-标志-矢量/标志-横版-中英全标.svg」，高度 40–44px；
   高度低于 40px（移动端约 26px）时改用「标志-横版-中文.svg」——英文小字太小会糊（见下）。
2. **反白版只用在深色背景上**，而且必须用 03 里的反白文件，不要拿彩色版套 CSS 滤镜凑数；
   浅色背景一律用主版本。
3. **favicon 三件套要齐**：`favicon.ico`、`favicon.svg`、`apple-touch-icon-180.png`，
   引用代码在「08-代码片段/favicon-seo-head.html」，整段贴进 `<head>` 即可。

## 安全空间与最小尺寸

- 标志四周留白 **≥ 图形标高度的 25%**，留白区内不放文字、图片或其他标志。
- **图形标**最小 16px（favicon 场景）；单独展示时建议 ≥24px。
- **横版-中英全标**最小高度 **40px**：英文标准字笔画细，低于这个尺寸会糊；
  更小场合用「横版-中文」（最小 26px）或只用图形标。
- **中文标准字已转成矢量轮廓**，不要换个字体把品牌名重新打一遍——字形、字距都对不上。
- favicon 的 16px / 32px 是**特殊小尺寸版**：经实测，底牌版在小尺寸下图形糊成一团，
  故这两个尺寸改为品牌色图形直接占满画布（无底牌），48px 起恢复底牌版；ICO 内含
  16 / 32 / 48 三个尺寸，用的就是这套。favicon.svg 仍为底牌版（大尺寸场景无碍）。

## 字体与素材来源

- 中文字标：思源黑体（Noto Sans SC）850 字重转矢量轮廓；英文字标：Barlow Bold 转轮廓。
  两者都是开源字体（OFL / Apache），演示换正式项目时无需另购字体授权。
- 图形标与导航图标：Phosphor 图标库（ISC 许可）——图形标为 fill 实心款，
  07 的导航图标为 regular 描边款（24px 网格、currentColor 随字色变色）。
- 06 的 hero 照片底图来自本内容包图包（packs 图包 hero 图），正式交付时换客户实拍。

## 制作说明（怎么派生的，如实记录）

- 母版是演示站系统已定版的标志三件（delivery-drill/logo-masters/ 的 logo.svg / logo-reversed.svg /
  logo-mono.svg）。本包把母版**拆件**（底牌+图形 / 中文字路径 / 英文字路径）后按原坐标
  重新组合出横版-中文、竖版等新版式，部件本身逐像素未动，所以新版式与在站页头完全一致。
- 02 的 PNG 是对应 SVG 的矢量渲染（CairoSVG），不是截图放大；OG、微信图与 hero 海报
  由程序合成（Pillow）：矢量件 + 内容包 tagline 与 hero 照片。hero 照片 PNG 经
  256 色抖动量化压缩体积（约 0.9 MB/张，背景用途肉眼无差）；要无损版时用内容包
  图包的原始 hero.jpg 按同版式重出即可。
- 单色的品牌色 / 深灰 / 黑三版由主版部件换色生成（底牌与文字取单色、图形反白镂空）；
  深炭版即系统母版 logo-mono.svg。
